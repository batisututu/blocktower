# Blocktower design entry point

The game is an 8×8 block puzzle whose cleared lines permanently grow a customizable tower. The detailed Korean documents remain the design source of truth.

- [Current document index](docs/README.md)
- [Upper game design v0.4](docs/Blocktower_Upper_Game_Design_v0.4.md): common rules and Phase numbering.
- [Growth plan v0.3](docs/Blocktower_Growth_System_Plan_v0.3.md): progression and segment boundaries.
- [Skin decision v0.3](docs/Blocktower_Visual_Bible_BlockSkin_Decision_v0.3.md): visual states and B/C direction.
- [Technical research](docs/Blocktower_Godot_Tech_Research_2026.md): state, persistence, engine, and integration contracts.
- [Development readiness v0.2](docs/Blocktower_Predevelopment_Readiness_v0.2.md): current evidence, preparation, and next implementation task.

The initial playable scope is Phase 1 plus a minimal wooden tower from Phase 2. Supply weights, target-device assumptions, and observation parameters remain experimental. Review completion is not production implementation or release approval.
