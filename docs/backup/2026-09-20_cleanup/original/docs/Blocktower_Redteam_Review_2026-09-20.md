## 2. Claude Code 협의

기존 Blocktower 폴더의 Claude Code 세션에 위 지적과 독립 검토 요청을 전달했다.
CLI 수신 결과의 `input_accepted` 및 `turn_started`를 확인했다.
Claude Code는 원본 3개 문서와 PNG를 직접 읽고 [독립 검토 의견서](Blocktower_Claude_Review_2026-09-20.md)를 작성했다.
이어 Codex의 채택/반론을 전달했고, Claude Code가 회신 내용을 확인하여 파츠 예외 기각·수신 주차 허점·검증 전 단정 배제에 동의한 최종 응답을 확인했다.
검토 원문 및 작성 중의 초안 대조표는 이력으로 보존한다. **원문 중 ‘사용자 판단 필요’와 미정 목록은 아래 최종 판단으로 갱신된다.**

| Claude 제안 | 최종 판단 | 반영 / 근거 |
|---|---|---|
| 저장 버전 전환·보드 파생 대기 줄·재현용 사건 로그 | 채택·범위 제한 | 상위 29/35절. 진단 로그는 보관 한도·스냅샷을 두며 서버 인증 증거와 구분 |
| 재질당 1개 동시 클리어 전용 프레스티지 파츠 | 기각, Claude 회신 동의 | 외형 때문에 선호 모드 변경을 강제하지 않는 원칙 우선. 모든 파츠 이중 경로 유지 |
| 서버 수신 시각으로 주간 기록 귀속 | 단독 정책 미채택, Claude 회신 동의 | 오프라인 기록 몰아 제출 가능. 유효기간·서버 시드·지연 한도와 함께 D10에서 결정 |

| 블록 생성은 P0, 최소 1개 배치 가능 보장 | 우선순위 채택, 보장 정책 유보 | 무보정/가방/보장 정책 비교 후 D03 결정. 대기 줄을 보류하여 공급에 영향을 주는 사례 포함 |
| 층 타일/레이어·직교 카메라·비계 | 비교 후보 채택 | 상위 37.1절. 고정 각도·픽셀·상호 그림자·메모리 실측 후 확정. 18장 에셋/60fps를 확정 예산으로 쓰지 않음 |
| 새 구간 스타일 자동 상속 | 현재 미채택 | 최소형은 목재 기본값. 반복 편집 부담 관찰 후 ‘앞으로 생성할 구간의 기본 스타일’ 설정 검토 |

| 용어집·타입 계약 | 용어집 채택 | 상위 38절. 코드 폴더/프로젝트 규칙 파일 신설은 이번 문서 검토 범위에 포함하지 않음 |
| 판 종료 후 탑 자동 진입 | 미채택 | 자발적 탑 확인을 관찰할 수 있도록 선택 진입 유지. 상세 완성 연출은 탑 진입 시 |

### 검토 원문의 오류·과장 정정

- Claude GO-1의 ‘빈칸 0 + 대기 1줄’은 불가능한 보드다. 빈칸이 0이면 가로 8+세로 8=16줄이다. Claude도 회신에서 오류를 인정했다. 구현 사례는 상위 35.4절의 조건과 실제 유효 보드를 사용한다.
- ‘자동 최대 6줄’은 특정 조각 집합에 의존한다. 카탈로그 미정 상태의 확정값으로 옮기지 않았다. Claude도 제한을 확인했다.
- 파일 rename의 원자성/내구성, 손실이 항상 1행동 이내라는 단정은 채택하지 않았다. 실제 대상 플랫폼에서 강제 종료·손상 복구로 저장 계약을 검증한다.
- ‘3×3/I-5’, 864/64/18장, 1px, 60fps, 해금 확률·첫 판 해금 빈도·테스터 수치는 Claude의 가정/예시다. 실측 또는 승인된 제품 규격으로 취급하지 않는다.
- 같은 배치 순서만으로 자동/수동의 전체 결과가 같다고 보장하지 않는다. 자동 제거 때문에 보드가 달라질 수 있으므로 모드별 유효한 행동과 상태에서 비교한다.

## 4. 변경 및 검증 이력

- 새 버전: 상위 v0.4, 성장 v0.3, 스킨 v0.3. 원본 3개 MD와 PNG는 보존한다.
- B/C 역할은 바꾸지 않았다. 이미지의 문제는 수정 요구사항으로 정리했으며 이미지를 새로 제작한 것은 아니다.
- Godot 4.7.2 Stable은 [공식 릴리스 아카이브](https://godotengine.org/download/archive/4.7.2-stable/)에서 확인했다(2026-09-20). 승인된 엔진 방향 유지.
- 줄/셀 합집합·점수 산식 81개 조합과 구간 경계 4개 사례를 계산해 예시의 정합성을 확인했다. 게임 로직을 실행한 테스트는 아니다.
- 최신 문서와 검토 기록의 로컬 링크, UTF-8 읽기, Markdown 코드 블록 닫힘, 남은 병합 충돌 표식을 확인했다.
- 기존 3개 문서는 입력으로만 읽어 보존했고 PNG도 변경하지 않았다. 작업용 편집 스크립트는 제거했다.
