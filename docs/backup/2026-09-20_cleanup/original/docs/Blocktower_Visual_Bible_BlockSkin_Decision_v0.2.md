# Blocktower Visual Bible — Block Skin Decision v0.2

- 기준일: 2026-09-20
- 상태: 확정
- 대상: 퍼즐 블록 디자인 / 스킨 상품화
- 상위 문서: Blocktower Visual Bible v0.1

---

## 1. 확정 내용

Blocktower의 퍼즐 블록 디자인은 **B안과 C안을 모두 채택**한다.

### B안 — Structural Frame

**기본 무료 블록 디자인**

- 모든 이용자에게 기본 제공
- Blocktower의 대표 기본 비주얼
- 건축 구조 프레임을 연상시키는 외곽 구조
- Matte Surface
- 내부 Frame 및 미세한 Chamfer 표현
- 작은 화면에서 가독성을 우선
- 퍼즐 규칙, 점수, 성장 시스템의 기준 외형으로 사용

### C안 — Layered Slab

**유료 코스메틱 스킨**

- 선택 구매형 유료 스킨
- 층판/슬래브 구조를 연상시키는 외형
- 수평 Band와 Layer 표현을 통해 “층을 쌓는다”는 콘셉트를 강화
- B안과 구분되는 전용 표면 디테일과 클리어 연출 사용
- 퍼즐 능력치나 보상에는 영향을 주지 않음

---

## 2. 상품화 원칙

C안은 단순 색상 변경이 아니라 **완성된 코스메틱 세트**로 구성한다.

### C 스킨 포함 범위

- 블록 기본 형태
- 표면 재질감
- 수평 Layer/Band
- 미세 구조선
- 배치 Preview 스타일
- 완성 줄 Highlight
- 전용 Light Sweep
- 전용 클리어 VFX

단, 게임 플레이에 영향을 주는 요소는 변경하지 않는다.

---

## 3. Pay-to-Win 방지 원칙

B와 C 사이에 다음 차이를 두지 않는다.

- 점수 보너스
- 블록 크기
- 충돌 판정
- 배치 가능 범위
- 클리어 판정
- 동시 클리어 배율
- 탑 층수 증가
- 재질 해금 속도
- 성장 보상
- 난이도

즉,

> **C 스킨은 100% 외형 전용 상품**

으로 운영한다.

---

## 4. UX 일관성 규칙

유료 스킨이라도 퍼즐 가독성을 해치면 안 된다.

### 공통 유지 요소

- 셀 크기
- 블록 실루엣 외곽 기준
- 배치 Preview 위치
- 완성 줄 표시 강도
- 수동 클리어 인지성
- 색각 접근성
- 작은 화면 가독성

C안은 더 화려할 수 있지만,
게임 정보를 숨기거나 오인시키는 효과는 금지한다.

---

## 5. B / C 역할 구분

| 구분 | B안 Structural Frame | C안 Layered Slab |
|---|---|---|
| 제공 방식 | 기본 무료 | 유료 코스메틱 |
| 역할 | Blocktower 기본 아이덴티티 | 프리미엄 시각 변형 |
| 형태 | 구조 프레임 중심 | 층판/레이어 중심 |
| 표면 | Matte / Structural | Matte / Layered |
| 클리어 연출 | 기본 Architectural Sweep | 전용 Layered Light Sweep |
| 게임 성능 | 동일 | 동일 |
| 성장 효과 | 동일 | 동일 |
| 경쟁 영향 | 없음 | 없음 |

---

## 6. Visual Bible 반영 원칙

Blocktower의 기본 화면 및 마케팅 대표 이미지는
**B안 Structural Frame**을 기본 기준으로 제작한다.

C안은 다음 영역에서 프리미엄 스킨으로 노출한다.

- 스킨 선택 화면
- 상점
- 미리보기
- 이벤트 배너
- 플레이 화면 적용 예시

단, C안이 기본 스킨보다 “더 강한 블록”처럼 보이지 않도록
UI 문구와 연출을 조정한다.

---

## 7. 컬러 팔레트 상태

현재 **블록 디자인은 확정**, 최종 컬러 팔레트는 미확정이다.

다음 단계에서 각각 별도 확정한다.

### B 기본 스킨
- 기본 무료 팔레트
- 높은 가독성
- Blocktower 대표 브랜드 컬러

### C 유료 스킨
- 기본 팔레트와 명확히 구분
- 층판 구조와 빛 표현을 강화
- 단순 색상 변경 이상의 프리미엄 인상

## 최종 확정 문장

> **Blocktower는 B안 Structural Frame을 기본 무료 블록 디자인으로 사용하고, C안 Layered Slab을 유료 코스메틱 스킨으로 제공한다. 두 디자인은 퍼즐 성능과 성장 보상에서 완전히 동일하며, 차이는 시각적 표현과 전용 클리어 연출에만 둔다.**
