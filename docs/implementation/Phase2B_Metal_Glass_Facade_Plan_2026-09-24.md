# Phase 2-B: 금속·유리 기본 외벽

기준일: 2026-09-24. Sol이 계획과 독립 검증을 맡고, 옆 창의 GPT-6 Luna가 구현·개발 실행을 맡는다. 사용자 요청대로 사람 관찰과 최신 Android 실기기 검증은 이후에 진행한다.

## 범위

기존 `GameSession.SET_SEGMENT_STYLE`과 `Growth.describe()`의 `metal` 해금 가안(한 번에 3줄 이상 제거 또는 누적 100층)을 그대로 사용한다. 완성된 10층 구간에 목재·벽돌·금속·유리 외벽 중 해금된 재질을 선택해 적용한다. 금속·유리는 하나의 재질이다. 미완성 구간과 잠긴 재질은 변경할 수 없다. 새 구간은 계속 목재로 시작하고 대표 구간은 독립적으로 유지된다.

세 재질 선택은 320×568 큰 글씨·상하 24px 안전 영역에서 48px 조작 목표와 읽을 수 있는 잠금·현재 상태를 제공한다. 재질 수가 늘어도 좁은 버튼에 문구를 줄여 넣지 않도록 선택 시트를 사용한다. 시트의 뒤로·닫기·키보드 포커스, 저장 실패·재개 시 화면 상태를 기존 입력 경계에 맞춘다. 금속·유리의 해금 경로는 **동시 3줄 또는 누적 100층**으로 명시한다. 크리스털은 아직 미제작 선택지로만 안내하고 적용하지 않는다.

금속·유리 외벽은 기존 640×480 캔버스, (320,240) 앵커, 106.4683685px 층 간격, 카메라·광원을 공유하는 편집 가능한 Godot 3D 원본과 투명 PNG로 만든다. 금속 프레임과 큰 유리창이 목재·벽돌의 창 및 구조선과 구별되어야 한다. 기존 바닥·지붕·중간 마감의 층수 표현을 유지한다. 색상 tint만 입힌 복제본은 완성으로 보지 않는다.

크리스털 외벽, 벽돌/금속 파츠 장착, 수치 조정, 전체 탑 합성 및 상점은 이번 범위 밖이다. 금속·유리와 목재/벽돌의 위아래 경계 샘플을 검사하되, 2층 샘플을 전체 탑 승인으로 표시하지 않는다.

## 완료 조건

1. 실제 탑 화면에서 잠긴 금속·유리, 해금된 선택지, 현재 적용 재질을 구분할 수 있다. 320×568 기본·큰 글씨·24px 안전 영역과 360×800/412×915에서 시트·탑·조작 버튼이 겹치지 않는다.
2. 저장 커밋이 성공한 뒤에만 외형이 바뀐다. 다른 구간의 목재·벽돌은 유지하고 재실행 후 금속·유리 설정이 복원된다. 잠긴 재질·미완성 구간·같은 재질 재선택·저장 실패가 기록을 바꾸지 않는다. 크리스털 저장값이 있는 기존 데이터는 보존한다.
3. 금속·유리 원본과 PNG가 재생성 가능하고 에셋 등록부에 출처·크기·해시가 기록된다. 재질 경계 양방향의 실제 Godot 2층 샘플에서 눈에 띄는 틈·밝은 알파 테두리가 없다.
4. 고정 Godot 4.7.2/GUT 9.7.1 전체 검사에서 파서 오류·실패·pending·0건 발견이 없다. Sol이 코드·저장·Windows 캡처를 독립 검증한다.

이번 결과는 기본 외벽 한 종류를 추가하는 제한된 구현이다. 실제 손가락 조작, 소리·진동 체감, 장시간 성능, 사람의 해금 경로 이해와 Android 최신 빌드는 검증하지 않는다.

## 구현·검증 결과 (2026-09-24)

옆 창의 GPT-6 Luna가 금속·유리 3D 원본 4종과 투명 PNG 4종, 재질 선택 시트, 저장 커밋 연결, 경계 캡처 도구를 구현했다. [에셋 원본 안내](../../art_source/visual_bible/README.md)와 `art_source/visual_bible/manifest.json`에 재생성 명령·출처·파일 크기·SHA-256을 기록했다. Sol이 등록부의 86개 항목을 다시 대조해 누락·해시 불일치 0건을 확인했다. 코어 해금 수치, RNG, 점수, 저장 스키마는 변경하지 않았다.

Sol은 고정 Godot 4.7.2/GUT 9.7.1 전체 검사를 별도로 재실행했다. **9개 suite, 118개 테스트, 3,328개 assertion, 실패·오류·pending 0건**이다. 실제 재질 버튼 입력으로 목재·벽돌·금속·유리 적용 값이 각각 전달되는지, 저장 실패 시 화면·기록이 이전 값에 머무는지, 다른 구간과 재실행 복원, 잠김·미완성·같은 재질·크리스털 기존 저장값을 확인했다. 크리스털은 선택 불가로 표시하고 기존 저장값을 유지하며 목재 그림으로 표시한다.

별도 출력 폴더 `tools/out/phase2b_sol_verify_20260924/`의 Windows 네이티브 화면 8종에서 **102개 점검이 모두 통과**했다. 320×568 기본·큰 글씨·상하 24px 안전 영역, 360×800, 412×915에서 시트 상태와 48px 선택지·스크롤 도달·뒤로가기 포커스 복귀를 검사했다. [320×568 큰 글씨·안전 영역 시트](../../tools/out/phase2b_sol_verify_20260924/inset_text_facade_sheet_locked_320x568.png)와 [금속 탑](../../tools/out/phase2b_sol_verify_20260924/facade_style_probe_320x568.png)을 눈으로 확인했다. 창·프레임은 목재·벽돌과 구별된다.

`python tools/capture_facade_seams.py --output tools/out/phase2b_seam_sol_verify_20260924`로 목재↔금속·유리와 벽돌↔금속·유리 **4방향** 실제 Godot 2층 샘플을 별도 재생성했다. 공통 640×480 캔버스·(320,240) 앵커·106.4683685px 층 간격과 겹침 구간의 빈 실루엣 행 0개를 확인했고, 네 이미지를 눈으로 대조해 눈에 띄는 틈이나 밝은 알파 테두리를 발견하지 못했다. 상세 실행 결과는 `tools/out/phase2b_metal_glass/report.json`과 Sol 별도 폴더의 `summary.json`에 남겼다.

이 판정은 금속·유리 기본 외벽의 Windows 구현 범위에 한한다. 크리스털과 파츠, 전체 탑 합성, 사람 관찰과 최신 Android 빌드·실기기 검증은 완료하지 않았다. §2 G2 관문 전체 통과로 기록하지 않는다.
