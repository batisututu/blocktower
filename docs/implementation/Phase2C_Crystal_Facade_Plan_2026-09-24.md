# Phase 2-C: 크리스털 기본 외벽

기준일: 2026-09-24. Sol이 계획·독립 검증을 맡고 옆 창의 GPT-6 Luna가 코드·에셋 구현을 맡는다. 사용자 요청에 따라 사람 관찰과 최신 Android 실기기 검증은 이후에 진행한다.

## 범위

기존 `Growth.describe()`와 `GameSession.SET_SEGMENT_STYLE`의 크리스털 해금 가안(한 번에 4줄 이상 제거 또는 누적 250층)을 변경하지 않고 완성된 10층 구간에 네 번째 기본 외벽을 연결한다. 이전 버전이 저장한 `crystal` 값은 기록 수정 없이 바로 크리스털 그림으로 표시한다. 목재·벽돌·금속·유리 구간, 대표 구간과 신규 목재 구간은 독립적으로 유지한다.

기존 선택 시트는 해금·잠금·현재 상태를 읽을 수 있게 표시하고 320×568 큰 글씨·상하 24px 안전 영역에서도 48px 선택지를 스크롤로 조작할 수 있어야 한다. 크리스털 잠금 기준은 **동시 4줄 제거 또는 누적 250층**으로 적는다. 저장 성공 뒤에만 외형을 바꾸며, 저장 실패·같은 재질·미완성 구간·잠긴 재질·뒤로가기에서 기록이 변하지 않아야 한다.

크리스털 외벽은 기존 640×480 캔버스, (320,240) 앵커, 106.4683685px 층 간격과 공통 카메라·광원을 사용하는 편집 가능한 Godot 3D 원본 및 투명 PNG 네 층 모듈로 만든다. 다각형 결정 구조와 빛을 받은 면이 기존 세 재질과 구별되어야 한다. 발광은 Windows Compatibility 렌더러에서 흰 덩어리로 뭉개지지 않아야 한다. 기존 바닥·지붕·층수 규칙을 유지하며 색상 tint 복제만으로 끝내지 않는다.

파츠, 첨탑·지붕 별도 편집, 해금 수치 조정, 전체 탑 합성, 상점은 이번 범위 밖이다. 다른 세 기본 외벽과 크리스털의 위아래 경계는 양방향 실제 Godot 2층 샘플로 확인하되, 이를 전체 탑 승인으로 확대하지 않는다.

## 완료 조건

1. 실제 탑에서 잠김·해금·현재 크리스털을 구분하고, 기존 크리스털 저장값을 추가 커밋 없이 그림으로 복원한다. 320×568 기본·큰 글씨·24px 안전 영역과 360×800/412×915에서 시트·버튼·탑 표시가 겹치지 않는다.
2. 실제 선택 버튼의 입력은 올바른 재질을 커밋한다. 잠김·미완성·재선택·저장 실패는 기록·표시를 바꾸지 않으며, 다른 구간의 세 재질과 재실행 복원이 유지된다.
3. 편집 가능한 3D 원본과 PNG 네 개, 해시·크기·출처가 에셋 등록부에 남는다. 목재/벽돌/금속·유리↔크리스털 여섯 방향 2층 경계에 눈에 띄는 틈·밝은 알파 테두리가 없다.
4. 고정 Godot 4.7.2/GUT 9.7.1 전체 테스트에서 파서 오류·실패·pending·0건 발견이 없고, Sol이 별도 출력 폴더에서 Windows 화면·경계·등록부를 독립 확인한다.

이 결과는 네 번째 기본 외벽의 Windows 구현이다. 사람의 해금 경로 이해, 장시간 게임필, Android 최신 빌드·실기기, 파츠·Phase 2 전체·G2 관문은 별도 검증이다.

## 구현·검증 결과 (2026-09-24)

옆 창의 GPT-6 Luna가 다각형 창·육각 기둥·절제된 발광면으로 구성한 크리스털 3D 원본 4종, 투명 PNG 4종과 기존 재질 선택 시트 연결을 구현했다. 기존 `crystal_lines >= 4` 또는 `total_floors >= 250` 해금값과 `SET_SEGMENT_STYLE` 저장 계약을 사용한다. 저장돼 있던 크리스털 구간은 추가 커밋 없이 즉시 크리스털 그림으로 표시한다. 점수·RNG·저장 스키마·기존 외벽 에셋은 바꾸지 않았다. 원본 재생성 명령과 출처는 [에셋 안내](../../art_source/visual_bible/README.md)에 기록했다. Sol이 `manifest.json`의 **96개 파일** 크기·SHA-256을 독립 대조해 오류 0건을 확인했다.

Sol은 고정 Godot 4.7.2/GUT 9.7.1 전체 검사를 다시 실행했다. **9개 suite, 119개 테스트, 3,342개 assertion, 실패·오류·pending 0건**이다. 실제 재질 선택 버튼, 잠김·미완성·같은 재질, 저장 실패, 다른 구간 독립성 및 재실행 복원을 포함한다.

별도 출력 폴더 `tools/out/phase2c_sol_verify_20260924/`의 Windows 네이티브 화면 **11종·157개 점검이 모두 통과**했다. 320×568 큰 글씨·상하 24px 안전 영역의 [선택 시트](../../tools/out/phase2c_sol_verify_20260924/inset_text_facade_crystal_unlocked_320x568.png)와 [스크롤 끝 화면](../../tools/out/phase2c_sol_verify_20260924/inset_text_facade_crystal_scrolled_320x568.png)에서 크리스털 버튼 전체 48px가 스크롤 창 안에 있고 고정 닫기 버튼 위에 있음을 좌표·이미지로 확인했다. [이전 저장값 복원 탑](../../tools/out/phase2c_sol_verify_20260924/inset_text_tower_legacy_320x568.png)은 크리스털 외형을 보여준다. 360×800과 412×915 화면도 통과했다.

`python tools/capture_facade_seams.py --set crystal --output tools/out/phase2c_seam_sol_verify_20260924`로 목재/벽돌/금속·유리↔크리스털 **6방향** 실제 Godot 2층 샘플을 별도 재생성했다. 공통 640×480 캔버스·(320,240) 앵커·106.4683685px 층 간격, 빈 겹침 행 0개를 확인하고 여섯 이미지를 대조해 눈에 띄는 틈이나 밝은 테두리를 발견하지 못했다. 같은 도구의 `--set phase2b`로 이전 금속 경계 **4방향**도 별도 재생성해 통과했다. 두 층의 증거를 전체 탑 합성 승인으로 확대하지 않는다. 상세 실행 결과는 `tools/out/phase2c_crystal/report.json`과 Sol 별도 출력 폴더에 남겼다.

이번 판정은 네 번째 기본 외벽의 Windows 구현 범위다. 파츠·별도 지붕/첨탑 편집, 사람 관찰, 최신 Android 빌드·실기기 검증 및 §2 G2 관문 전체 승인은 완료하지 않았다.
