# Phase 2-H: 높은 탑의 구간 이동

기준일: 2026-09-25. 성장 기획 §6의 구간 점프를 현재 구간 감상 화면에 연결한다.

## 범위와 계약

탑에 두 구간 이상 있으면 상단에 `구간 이동` 48px 버튼을 표시한다. 선택창에 1부터 `완성 구간 수 + 미완성 구간 0~1개`까지의 정수 번호를 입력한다. 잘못된 번호는 선택창을 유지하고 입력 오류를 표시한다. 올바른 번호는 해당 구간의 기존 층·외벽·파츠·대표 상태를 다시 그린다. 마지막 미완성 구간도 볼 수 있지만 기존 규칙대로 외벽과 대표 편집은 비활성화한다. 이전/다음 구간 버튼은 유지한다.

`selected_segment`는 화면 지역 상태다. 구간 이동은 `GameSession.dispatch()`를 호출하지 않으므로 revision, 저장 파일, 점수, 성장, 해금, 대표 구간, 공급 RNG에 영향을 주지 않는다. 취소와 시스템 뒤로가기는 현재 선택을 유지한다. 입력창의 Enter 처리와 이동 버튼은 화면 세대·앱 활성 상태 경계를 따른다. 구체 계약은 [표현 계약](../../game/scripts/core/contracts/presentation_contract.md)의 `Tower segment jump` 절에 있다.

## 구현과 현재 확인

`puzzle_screen.gd`의 탑 제목 오른쪽에 이동 버튼을 추가하고, 하단 시트에 현재 구간 번호가 들어간 48px 입력칸을 제공한다. 입력값이 1~최대 구간의 정수인지 확인한 뒤 화면만 다시 구성한다. 잘못된 값은 바로 아래에 범위 안내를 표시한다. 모달을 닫거나 화면을 다시 구성할 때 입력 참조를 제거하며, 이전 화면 세대의 Enter 신호는 무시한다.

고정 Godot 4.7.2의 headless editor import가 종료 코드 0으로 끝났고 파서 오류가 출력되지 않았다. 이번 작업에서 GUT, 네이티브 화면 입력 검사, Android 빌드·실기기 검증은 실행하지 않았다. 작은 화면과 Android 숫자 키보드 사용성은 후속 관찰 범위다.
