# Phase 3 건축 MVP: 전체 탑 감상과 단일 구간 외형 복사

기준일: 2026-09-25. 게임 기획 §36의 Phase 3 최소 구현과 성장 기획 §5~6을 현재 `bt_session_v2`에 연결한다. 30/300/3,000층 체험·성능 수용은 별도 확인이 필요하다.

## 구현 범위

- 기존 고정 카메라·광원·층 앵커의 재생성 가능한 프리렌더와 구간별 외벽·벽돌 파츠 편집을 유지한다. Phase 2-H의 번호 이동으로 완성 구간과 마지막 미완성 구간을 찾는다.
- 전체 탑 감상 화면은 정확한 누적 층수·최고점·완성/진행 구간·재질별 층 비율을 보인다. 현재 구간은 금색 선, 대표 구간은 원형 표식과 별도 이동 버튼으로 찾는다. 높이 그림은 최대 64개 구간 띠로 축약하며 실제 층마다 노드나 텍스처를 만들지 않는다. 희소 `segment_styles`에서 비율을 계산하므로 3,000층뿐 아니라 더 높은 탑도 층수에 비례해 순회하지 않는다. 후속 보완에서 작은 화면의 구간 외형 확대와 0보다 큰 작은 재질 비중 표시를 추가했다.
- 완성된 구간 하나의 **보이는 외형**을 다른 완성 구간 하나에 복사한다. 재질과 벽돌 장식을 한 번의 `COPY_SEGMENT_APPEARANCE` 커밋으로 바꾸며, 비벽돌 원본의 휴면 벽돌 장식은 복사하지 않는다. 대상의 기존 장식 기록은 교체된다. 대상 번호와 복사 전·후 외형을 먼저 보여주고 취소할 수 있다. 잠김 파츠 우회는 불가능하며 미완성·동일·무효 대상은 커밋하지 않는다. 성공 시 대상 구간을 연다.

## 상태·저장 경계

전체 탑 보기, 구간 이동, 대표 구간으로 돌아가기는 화면 지역 상태이며 파일·revision·RNG를 바꾸지 않는다. 외형 복사는 기존 `bt_session_v2`의 `segment_styles`와 `segment_parts`만 후보 상태에서 수정한다. 두 필드를 함께 한 번에 커밋하고 성공 후 `TOWER_CHANGED`를 발표한다. 실패·경합·불확정 커밋의 기존 복구 경계를 따른다. 점수·층수·대표 선택·조각 공급 체크포인트는 그대로다. 상세 계약은 [GameSession](../../game/scripts/core/contracts/game_session_contract.md)과 [표현 계약](../../game/scripts/core/contracts/presentation_contract.md)에 기록했다.

## 범위와 확인 상태

이번 MVP 복사는 단일 대상이다. 여러 구간 전체 적용과 직전 일괄 편집 되돌리기는 포함하지 않는다. 초기 구현 시점에는 간이 가져오기만 수행했다. 이후 고정 엔진 검사에서 파서 오류 한 건을 발견·수정하고 GUT, Windows 네이티브 화면·실제 파일 재시작, 30/300/3,000층 호스트 계측을 [데스크톱 보완·검증 기록](Phase3_Desktop_Validation_2026-09-25.md)에 남겼다. Android 최신 소스 실기기·사람 관찰 및 기기 예산 판정은 남아 있어 Phase 3 수용 관문 전체 통과로 기록하지 않는다.
