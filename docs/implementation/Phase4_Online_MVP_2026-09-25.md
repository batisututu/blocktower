# Phase 4 온라인 MVP 구현

기준일: 2026-09-25. [온라인 계약](../../game/scripts/core/contracts/online_phase4_contract.md)과 [ADR-0008](../adr/0008-phase4-verified-weekly-challenge.md)의 작업 정책으로 서버와 게임 화면을 연결했다.

## 구현

- Python 표준 라이브러리 HTTP/SQLite 서버가 임시 게스트 계정, UTC 월요일 시작 주차, 계정당 주 1개 서버 시드, 검증된 주간 순위와 대표 구간을 관리한다. 서버는 `GameSession` 재생 스크립트를 고정 Godot 엔진으로 실행하고 입력 행동이 아닌 결과 상태에서 층수를 도출한다.
- 도전 발급 시 `supply_profile`을 DB에 고정하고 클라이언트·검증 재생기에 전달한다. 기존 도전은 `classic`, 2026-09-28 UTC 시작 주차부터 새로 발급하는 도전은 `reduced_single`이다. [조정 범위](Piece_Tray_Refinement_2026-09-25.md)를 따른다.
- 게임의 `주간` 화면에서 서버 주소 설정, 도전 시작/이어가기, 검증 제출, 순위와 다른 사람의 대표 10층을 볼 수 있다. 외형은 검증 결과의 재질/장식만 프리렌더 에셋으로 읽기 전용 표시한다.
- 도전 진행은 개인 `user://save_v1`과 별도의 두 세대 행동 기록에 저장된다. 온라인 도전에서 새 게임을 차단한다. 개인 탑으로 돌아와도 기존 개인 저장은 변경하지 않는다.
- Android 프리셋은 versionCode 9/`0.1.0-phase4-9`와 인터넷 권한을 준비했다. 현재 기기의 본 앱 설치 상태는 변경하지 않았다.

## 작업 정책

순위는 검증 층수 내림차순, 해당 층수 최초 검증 시각, 계정 ID 순이다. 서버 발급 시드의 행동을 그 주가 끝나는 다음 월요일 00:00 UTC 전까지 받는다. 늦은 제출은 개인 도전 기록으로 남고 공개 순위에는 반영되지 않는다. 전주 행동을 다음 주에 옮기지 않는다. 동일 기록 재전송은 무변경, 기존 기록을 정확히 연장한 제출만 갱신한다. 서로 다른 기기에서 갈라진 기록은 자동 병합하지 않는다.

최초 MVP 시점에는 임시 계정 토큰 분실 후 복구를 지원하지 않았다. 이후 [복구 코드와 서버 도전 기록 이어받기](Phase4_Recovery_Conflict_2026-09-25.md)를 추가했다. 개인 탑의 기기 간 동기화와 점수 보상은 없다. 다른 탑은 서버 검증을 통과한 대표 구간만 노출한다. 이 정책은 D09/D10의 **MVP 작업 결정**이며 출시용 약속은 아니다.

## 로컬 서버 실행

고정 Godot 4.7.2 실행 파일을 지정해 저장소 루트에서 실행한다. 서버는 기본적으로 PC loopback에만 바인딩한다.

```powershell
python services/phase4/server.py --db C:/DEV/BlocktowerPrivate/phase4.sqlite3 --godot C:/DEV/tools/godot/4.7.2/Godot_v4.7.2-stable_win64_console.exe
```

Android 개발 기기에서는 별도 터미널에서 `adb reverse tcp:8765 tcp:8765`가 필요하다. 앱의 기본 주소는 `http://127.0.0.1:8765`다. 외부 서버 주소는 HTTPS만 허용한다. DB는 비밀 파일이므로 저장소 밖에 둔다.

## 현재 확인 범위와 남은 일

고정 Godot 가져오기와 GUT 141개/3,733개 단언, Windows 로컬 서버 HTTP 검사, Android QA 기기에서 도전·재시작 복원·제출·다른 대표 탑 보기를 확인했다. 수치와 화면은 [Phase 4 종단 간 검증 기록](Phase4_Local_E2E_Validation_2026-09-25.md)을 따른다. 공개 서비스를 위한 TLS 배포, 계정 복구·연결, 백업, 요청 제한, 운영 관측, 규칙 버전 교체 중 진행 중 도전의 재생기 유지, 여러 기기/시간 경계 실제 시나리오 검증이 남았다. Phase 4 전체 수용 관문은 아직 통과하지 않았다.

이 문단은 최초 MVP 시점의 범위다. 계정 복구·서버 행동 기록 이어받기·기기 분기 선택과 실기기 결과는 [후속 기록](Phase4_Recovery_Conflict_2026-09-25.md)을 현재 기준으로 사용한다.
