# Phase 4 계정 복구·기기 기록 충돌 후속

기준일: 2026-09-25. [온라인 계약](../../game/scripts/core/contracts/online_phase4_contract.md)을 versionCode 14 QA 앱과 로컬 Phase 4 서버에 적용했다.

## 구현

- 임시 계정이 128비트 복구 코드를 발급한다. 서버 DB에는 코드의 SHA-256 해시만 저장하며 새 코드 발급 시 종전 코드를 무효화한다. 계정 정보가 없거나 기존 토큰이 서버에서 거절된 앱에서 코드를 입력하면 기존 계정에 새 토큰을 발급하고 이전 기기의 토큰을 무효화한다. 유효한 다른 계정이 있는 앱은 이 경로로 계정을 덮어쓸 수 없다. 응답을 잃은 경우 같은 코드를 다시 사용할 수 있다. 코드를 앱 밖에 보관하지 않고 앱 데이터를 지우면 복구할 수 없다.
- 인증된 도전 발급 응답에 서버가 이미 검증한 행동 기록을 포함한다. 새 기기나 로컬 기록이 서버 기록의 정확한 접두사인 경우 재생·저장해 이어간다. 로컬 기록이 서버보다 길면 로컬 행동을 유지한다. 서로 갈라진 기록은 자동 병합하지 않는다.
- 갈라진 기록을 제출하면 선택 안내를 띄운다. 사용자가 확인한 경우 기기의 두 세대 행동 파일을 별도 비공개 충돌 폴더에 복사한 다음 서버 기록을 재생·저장한다. 보관에 실패하면 현재 기록을 교체하지 않는다. 개인 `save_v1`은 이 흐름에서 읽기만 한다.
- 기존 서버 DB의 `accounts` 표에 `recovery_hash` 열을 추가하는 마이그레이션을 적용했다. 공개 순위 응답에는 코드·토큰·원시 행동을 넣지 않는다.

## 확인 결과

- 고정 Godot 4.7.2/GUT 9.7.1: **147개 검사, 3,777개 단언**, 실패·오류·보류 0. 계정 복구 전용 로컬 HTTP **17항목**과 기존 DB 열 마이그레이션을 확인했다.
- Samsung SM-N981N/Android 13에 별도 `com.blocktower.game.qa` versionCode 10→14를 데이터 보존 업데이트했다. [개인 퍼즐 화면](version13_evidence_2026-09-25/personal_tray.png)에서 대기 조각의 판이 보이지 않았다. 새 개인 저장의 공급 해시는 `62a506b1995d513671e5b70abf840be0a8b5c9fbf4bb0cae83e91e7cde2617ad`로 `reduced_single`과 일치했다.
- QA 앱의 계정·도전 파일을 비공개 임시 공간에 백업한 뒤 제거하고, 발급한 코드로 같은 계정을 복구했다. 이전 토큰은 무효화됐고 서버의 행동 1개를 새 로컬 도전 파일로 복원했다. 조각을 하나 더 놓아 행동 2개로 서버에 연장 제출했다. 이 과정에서 개인 저장은 0회차·0층으로 유지됐다.
- 같은 도전의 3번째 행동을 기기에서는 `PLACE`, 서버에서는 `SET_AUTO`로 갈라지게 만들었다. 제출 시 `TRACE_NOT_EXTENSION` 안내를 표시하고 [선택 확인 창](version13_evidence_2026-09-25/conflict_choice.png)을 확인했다. 선택 후 기기 `PLACE` 기록 3개가 충돌 폴더에 남고, 현재 도전은 서버의 `SET_AUTO` 기록 3개로 전환됐다. [전환 후 화면](version13_evidence_2026-09-25/server_trace_restored.png)에서 점수 6과 자동 클리어 켜짐을 확인했다. versionCode 13 이상에서는 확인 창의 모든 문구가 화면 안에 표시된다.
- versionCode 14에서는 앱에 무효화된 종전 토큰 파일을 그대로 둔 채 복구 코드를 입력했다. 서버의 토큰 거절을 확인하고 새 토큰으로 복구했으며, [복구 안내 화면](version13_evidence_2026-09-25/stale_token_recovered.png) 이후 주간 도전 행동 4개를 다시 열었다. 개인 저장은 0회차로 유지됐다. 검증에 쓴 코드는 새 코드 발급으로 무효화했다.
- 실행 중인 검증 DB를 기존 백업 도구로 별도 SQLite 파일에 복사하고 `integrity_check`·외래키를 확인했다. 복원 사본에서 계정 인증, 현재 도전의 검증 행동 4개 조회, 순위 1개 조회가 통과했다. 이는 한 파일 복원 훈련이며 장애 시나리오 전체를 검증한 것은 아니다.
- 본 앱 `com.blocktower.game` versionCode 8과 사용자 저장은 변경하지 않았다. QA 기기의 복구 코드·토큰 및 로컬 서버 DB는 검증용 비공개 자료이며 저장소에 포함하지 않는다.

## 다음 관문

현재 검증은 한 기기와 `adb reverse` 로컬 서버에 한정된다. 공개 서비스 전에는 TLS 종단과 호스팅, 요청 제한·운영 관측, 백업 복원 훈련, 주차 경계 실제 시각 검사, 규칙 버전별 재생기 보존, 최소 지원 기기 및 사람 관찰이 필요하다. 충돌 폴더는 현재 앱 UI에서 다시 선택할 수 없으므로 지원·보존 정책도 정해야 한다.
