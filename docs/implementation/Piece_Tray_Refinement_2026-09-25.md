# 1칸 조각 빈도와 대기 조각 배경 조정

2026-09-26 수정: 사용자 가독성 피드백에 따라 이 문서의 배경 제거 결정은 [조각 트레이 복구 기록](Phase4_Request_Controls_2026-09-26.md)으로 대체했다. 1칸 조각 공급 설정은 유지한다.

기준일: 2026-09-25. 개인 퍼즐의 새 저장에 적용할 조각 공급 설정과 대기 조각 화면을 조정했다.

- 새 개인 저장의 `single` 계열 가중치는 5/45에서 1/41로 낮췄다. 이는 **보정 전** 각 슬롯의 비율이다. Easy 교체·배치 가능 보정 후 실제 출현 비율은 측정 전이며 0%를 보장하지 않는다. 한 수 보장에 필요한 양의 가중치는 유지한다.
- 기존 개인 저장은 체크포인트 해시를 기준으로 종전 설정으로 읽는다. 진행 중인 판의 공급열·저장을 재해석하지 않으며, 이 판에서 새 게임을 선택해도 종전 설정을 유지한다. 안전한 프로필 전환은 별도 저장 전환 작업이 필요하다.
- Phase 4 서버가 발급 도전마다 공급 프로필을 보관하고 클라이언트·재생 검증기에 전달한다. 기존 DB 행과 이번 주 도전은 `classic`이며, 2026-09-28 UTC 시작 주차의 새 도전부터 `reduced_single`을 사용한다. 진행 중 도전의 프로필을 교체하지 않는다.
- 대기 중인 세 조각 아래 어두운 트레이 판과 세로 구분선을 그리지 않는다. 조각 위치, 터치 영역, 놓을 수 없음 표시와 안내 문구는 기존 배치 좌표를 사용한다.
- 다음 Android 내보내기 프리셋을 versionCode 10으로 올렸다. 설치·화면 확인은 아직 수행하지 않았다.

새 설정의 공급 분포·저장 복원·서버 주차 전환은 [후속 실행 기록](Version10_Supply_And_Operations_2026-09-25.md)을 따른다. Android 화면과 실제 UTC 주차 전환은 아직 확인하지 않았다.
