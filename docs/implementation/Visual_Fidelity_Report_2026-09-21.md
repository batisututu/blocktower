# B안 세부 외형 재현 보고서

- 기준: 사용자 `B안` 선택 및 후속 요청 ‘시안의 세밀한 외형 재현까지 진행’.
- 시각 정본: [디자인 시안](../디자인시안.png)의 B×2 퍼즐과 Wood 탑.
- 적용 대상: 실제 `app.tscn`의 PuzzleScreen. 기존 W0 합성 화면과 W4 최초 증거는 보존한다.
- 대조 자료: [원본·실행 화면 비교](fidelity_evidence_2026-09-21/comparison.html), [실행 상태 목록](fidelity_evidence_2026-09-21/native/summary.json).

## 바뀐 외형

1. **블록:** 평면 색상 그리기를 6색 구조 타일 텍스처로 교체했다. 잘린 모서리, 면/베벨의 명암, 코너 이음선, 벽돌 구획과 작은 석재 입자를 독립 SVG 원본으로 제작했다. 13개 저장 스타일 ID는 같은 규칙 상태를 유지하며 6색 재질로 매핑한다.
2. **HUD:** 점수·최고점·수동/자동을 상단 스트립으로 묶고 보드 양옆에 실제 설정·탑 버튼을 배치했다. 보드/트레이/패널/클리어 버튼은 독립 9-slice 재질을 사용한다. 본문·점수·보상과 터치 영역은 실제 Godot Control이다.
3. **배경:** 과도하게 밝은 기존 궁전 배경을 낮은 채도의 황토색 아치·기둥·서가·식재·석재 바닥으로 교체했다. 보드 뒤 중앙은 조용한 벽면으로 두고 건축선은 가장자리에 배치했다.
4. **목재 탑:** 단순 상자층을 아치창·석재 쐐기돌·목재 골조·발코니·난간·식재·세 단계 외벽 폭·경사 지붕·기단 계단으로 교체했다. 수정 가능한 3D 장면 9개와 투명 프리렌더를 함께 보존한다. 동일 카메라/앵커/층 간격을 사용한다.
5. **표시:** 긴 점수/최고 기록은 별도 두 줄 배치로 정확히 표시한다. 여러 보상이 동시에 발생한 토스트도 기본 보상과 추가 정보를 두 줄로 나누어 마지막 한 글자만 고립되는 현상을 줄였다.

원본 시안의 3줄 예시 점수, 칸 배치, 상점·미션 메뉴를 실제 기능이나 규칙으로 복사하지 않았다. 실제 보드 8×8·3조각·수동/자동 규칙과 현재 제품 범위를 기준으로 정규화했다. 기존 저장·공급 알고리즘은 변경하지 않았다.

## 최종 검토

독립 검토 최종 판정은 **ship**이다. 지적된 정면 창·긴 화면 배경 프레이밍·지붕 줄눈·목재/식재의 4개 수정이 모두 해결됐다. 구도·블록 재질·배경·HUD·글자·탑의 6축은 일치 또는 명시한 적응 범위로 기록했다. 최종 판정은 해당 수정 목록과 Windows 캡처 범위이며 전체 제품/출시 승인이 아니다.

## 검증

고정 Godot 4.7.2 / GUT 9.7.1의 전체 **74개 테스트·2,592개 단언**이 통과했다. 실제 파일 세션에서 드래그→프리뷰→드롭→커밋 1회→저장 상태 일치를 다시 확인했다. 크기 변경, 저장 복구, 취소/포커스, 자동 확인, 최고 기록, 탑 경계 회귀도 기존 검사를 통과했다.

네이티브 Windows **19개 상태**를 캡처했다: 기본 320×568/360×800, 시안 대조 보드 360×800/412×915, 교차 412×915, 실제 입력·유효/무효·제거·최대 제거 360×800, 확인/설정·큰 정수 320×568, 1/9/10/11층과 13층의 중간/최상단 구간 360×800. 최종 지붕 재질만 변경한 뒤에는 오류 없는 import와 영향받는 탑 6상태를 다시 검증했다. 나머지 13상태는 동일한 UI/배경 코드의 직전 검증을 유지한다. 이 목록은 모든 상태×모든 해상도의 전수 검사가 아니다. `Input.parse_input_event` 경로이며 실제 Android 터치 증거가 아니다.

자체 대조에서는 탑 과노출·구간 탐색 영역 겹침·최대 알림 줄바꿈을 수정했다. 독립 검토에 따라 정면 유리 면을 외벽 앞으로 이동하고, 배경판 전체가 보이도록 비율별 fit을 변경했다. 목재/석재 대비와 불규칙한 잎사귀를 보강했다. 지붕 줄눈은 최종적으로 실제 메시에 묶인 UV 재질로 만들어 돌출 선 geometry를 제거했다. 최종 독립 검토와 6개 축 판정은 [finish-review](fidelity_evidence_2026-09-21/finish-review.md)에 기록한다. 원본과의 픽셀 일치, Android 실기기 품질, 사용자 최종 아트 승인을 자동 검사 통과로 주장하지 않는다.

```powershell
pwsh -NoProfile -File tools/test.ps1
python tools/verify_visual_fidelity.py

```

재현 시 새 출력 폴더를 사용한다. 검증 도구는 기존 fixture 프로필 재사용을 거부한다. 실제 앱은 기존 사용자 저장을 복원하며 새 게임을 임의 실행하지 않는다. W5의 실제 터치·safe area·폰트 확대·백그라운드·햅틱/성능 검증은 별도다.
