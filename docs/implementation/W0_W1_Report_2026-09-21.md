# W0/W1 실행 보고서

기준일: 2026-09-21. 기획·정책은 [현재 문서 안내](../README.md)의 7개 정본에서 관리하고, 이 파일은 실제 구현 범위와 실행 증거만 기록한다.

**후속 정정:** 사용자가 첨부 시안과 실행 화면의 불일치를 지적했다. 아래 W0 산출물과 시각 검토는 기능/레이아웃 초안 범위이며, 원본 외형 재현 완료가 아니다. W1 테스트 증거는 유지하고 W0 외형 작업은 다시 연다. 새 완료 조건은 [디자인 가이드 §11](../Blocktower_Design_Asset_Guide.md#11-첨부-시안-재현-기준과-제작-관문)을 따른다.

## 완료 범위

- **W0 첫 범위:** 기존 B 콘셉트를 바탕으로 원본 SVG 21개, 한글 폰트, 전체 HUD·합성 상태·목재 탑의 Godot 시안을 제작했다. 팔레트/크기/앵커/출처는 [디자인 가이드 §10](../Blocktower_Design_Asset_Guide.md#10-w0-첫-세트-제작-기록)에 기록했다.
- **W1:** 열린 Claude Code가 Git 초기화, 지속 경로 엔진, GUT 벤더링, 공급 예제 이식과 실행 스크립트를 구현했다. Codex가 출처 고정, 오류/0개 검사 거부, 바이트 보존, UI 상태 경계를 검토하고 최종 검사를 실행했다. 커밋·원격 저장소·배포는 수행하지 않았다.
- **현재 화면:** 점수·13층 등의 값은 합성 데이터다. 조각 선택은 프리뷰를 보여 주고 클리어/자동 전환은 시안 상태만 바꾼다. 실제 드래그 배치, GameSession, 영구 성장, 저장은 W2~W4 구현 대상이다.

| 검사 | 결과 | 증거 |
|---|---|---|
| 엔진/애드온 고정 | Godot `4.7.2.stable.official.ed1daf0bf`, GUT 9.7.1 커밋·146개 원본 해시 일치 | [출처/해시](../../tools/engine_provenance.json) |

| 공급 검사 | 위 9개 중 1개가 **기존 109개 조건 검사·30,000조각 진단**의 이식 결과를 검증 | `game/tests/unit/test_piece_supply_checks.gd`; 사람 난이도·최종 밸런스 검증 아님 |
| 모달 상태 | 버튼 신호를 통한 자동 전환 확인/취소, 취소 시 보드 보존, 배경 키보드 포커스 격리·복구, 화면 이동 통과 | `game/tests/unit/test_design_preview.gd`; 실제 손가락/마우스 조작 증거 아님 |
| 0개 검사 방어 | GUT exit=0/검사=0 결과를 wrapper가 **exit=1로 거부** | [0개 결과](evidence/zero_tests_rejected.json), [JUnit](evidence/zero_tests.xml) |
| 잘못된 엔진 방어 | PATH의 4.6.1 실행을 **exit=1로 거부** | [버전 거부 로그](evidence/wrong_engine_rejected.log) |
| 실제 렌더 | Windows OpenGL에서 3개 논리 크기, **13개 상태 캡처 성공** | [캡처 manifest](../design/captures/capture_manifest.json) |
| 독립 시각 검토 | compact 안내 겹침·포커스 버튼 대비·꽉 찬 보드 문구 수정 후 해당 5개 화면 재검토 통과 | [검토 기록](evidence/visual_review.md) |

검사 개수는 서로 중복 합산하지 않는다. 109개 조건 검사는 9개 GUT 테스트 중 하나에 포함된다. 기존 사전 검사 증거는 수정하지 않았고 이 보고서는 새 `game/` 대상의 실행 결과다.

## 미완료 범위와 다음 작업

1. **W2:** State/Action/Result 계약, 규칙 버전과 상태 소유권부터 정의한다. GameSession 배치·수동/자동·묶음·점수·성장 전이를 구현하고 R01~R07/R10을 검사한다.
2. **W3:** 상태 스키마 v1, 전체 커밋·실패·손상 복구·재개를 연결한다. 저장 성공 전 성장 이벤트를 발행하지 않는다.
3. **W4 디자인 통합:** 실제 입력, 글꼴 확대/긴 문구, 4줄+프리뷰 복합 상태, C 동등성, A08 모션·A09 음향은 남아 있다. 목재는 현재 정면 벡터 모듈이며 최종 Blender 2.5D 프리렌더 원본은 아직 없다.
4. **W5:** Android 기기 모델/OS, safe area, 터치, 템플릿·SDK·JDK 조합, 저장/복귀, 성능 검증을 수행한다. Android 세로는 기존 작업 가안이며 사용자 플랫폼 선택 확정으로 기록하지 않는다.

실행 방법은 [루트 README](../../README.md)를 따른다. 이 보고서의 desktop 캡처는 실기기 검증이나 플레이 가능 빌드 완료를 뜻하지 않는다.
