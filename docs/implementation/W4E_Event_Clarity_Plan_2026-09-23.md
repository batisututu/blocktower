# W4-E 복합 보상 안내와 데스크톱 첫 플레이 준비

기준일: 2026-09-23. Sol이 계획과 검증을 맡고, GPT-6-Luna가 코드 작성과 개발 실행을 맡는다. 사용자의 지시에 따라 Android 설치·실기기 검증은 이후에 진행한다.

## 다음 개발 작업

1. **작은 화면에서 누락되는 성장 안내 수정.** 현재 `puzzle_screen.gd`는 구간 완성·해금·연속 완성을 `growth_label`에 쓰지만, compact 레이아웃에서는 이 라벨을 숨긴다. 클리어·새 최고 기록·새 조각과 동시에 발생해도 새 구간과 해금 사실을 보드 밖에서 읽을 수 있도록 요약한다. 다음 조각을 집는 입력은 막지 않는다.
2. **복합 사건의 문구·크기 검증.** 9→11층, 19→21층, 다중 구간 완성, 해금+새 최고 기록+새 조각+게임오버, 최대 16줄 제거를 고정 상태로 재현한다. 320×568 큰 글씨·상하 24px 안전 영역과 360×800/412×915에서 글자 잘림, 알림 덮어쓰기, 실제 점수·층수와의 불일치를 확인하고 수정한다. 무음·감소 모션에서도 같은 핵심 정보를 전달한다.
3. **데스크톱 성능과 반복 체감 자료.** 30회 연속 입력과 최대 제거에서 입력 해제, 동시 효과음 요청 수, 노드·메모리 변화, Windows 프레임 시간의 p95/최대값을 같은 조건으로 기록한다. 수치는 Windows 관찰값으로 명시하며 모바일 성능 합격으로 해석하지 않는다.
4. **첫 플레이 관찰 준비.** 수동 클리어, AUTO 전환, 10/30층 목표와 탑 방문을 확인할 [데스크톱 관찰 초안](W6_Desktop_First_Play_Observation_Draft_2026-09-23.md)을 작성했다. 참가자·시간 상한·기록 범위는 실제 관찰 전에 정한다. 관찰 결과 없이 난이도나 연출 강도를 확정하지 않는다.

## 수용 기준

- 복합 사건마다 핵심 결과가 화면에 표시되고 저장된 점수·성장·공급 상태와 일치한다. 새 입력과 중단/복귀에서 과거 보상을 다시 지급하거나 재생하지 않는다.
- 320×568 기본/큰 글씨/안전 영역, 360×800, 412×915 실제 Godot 캡처에서 보드·트레이·조작 버튼을 가리지 않고 안내를 읽을 수 있다. 긴 안내는 축약/줄바꿈/후속 확인 중 명확한 방식으로 처리한다.
- 고정 Godot 4.7.2/GUT 9.7.1 전체 테스트와 해당 Windows 네이티브 사건 검사에 실패·오류·pending이 없다. Sol이 코드를 읽고 결과·캡처를 별도로 확인한다.
- 실기기 소리·진동·손가락 체감, 장시간 발열·기기 프레임은 이번 완료 판정에 포함하지 않는다.

이 작업 뒤에는 데스크톱 첫 플레이 관찰로 규칙 이해와 반복 피로를 확인하고, 사용자 요청 시 최신 빌드의 Android 실기기 검증을 진행한다.

## 구현 및 Sol 검증 결과

- Luna가 클리어 결과, 구간·해금 수, 기록·공급 상태를 최대 3개 알림으로 묶었다. 1개당 0.72초 표시와 0.15초 페이드로 최장 2.61초다. 빠른 다음 조각 선택은 대기 알림을 닫지만 입력은 계속되며, 탑 화면의 **해금 보기**에서 최근 구간·재료·장식 이름과 현재 저장된 해금 목록을 확인할 수 있다. 게임오버 결과창에도 복합 사건의 상세가 남는다.
- 실제 세션의 9→11층·19→21층 및 16줄·2구간 제거를 재현했다. 클리어 직후 재공급과 즉시 게임오버가 함께 나는 조합은 기본 공급 규칙에서 도달하지 않아, 해당 표시 경로만 고정 이벤트 테스트로 확인했다.
- Sol이 고정 Godot 4.7.2/GUT 9.7.1 전체 스위트를 독립 재실행해 **102개 테스트·3,124 assertions, 실패·오류·pending 0**을 확인했다. Luna의 최종 복합 화면 8종은 자동 검사 206개를 통과했고, Sol의 별도 화면 3종과 30회 연속 입력 검사도 통과했다. Sol은 320×568 기본·큰 글씨·안전 영역의 알림과 탑 상세 화면을 직접 확인했다.
- Windows 320×568 30회 입력에서 Sol 재실행 관찰값은 dispatch p95 194ms·다음 프레임 p95 19ms, 노드 수 변화 0이었다. 호스트 상태와 동기 저장을 포함한 값이라 모바일 성능 기준으로 쓰지 않는다. Android 빌드·설치와 실제 소리·진동·손가락 체감은 이번에 수행하지 않았다.
- [보존된 보고서·JUnit·캡처·Sol 재검사](w4e_evidence_2026-09-23/report.json)를 검증 자료 폴더에 모았다. 최근 클리어의 사건 순서는 현재 화면 세션에만 남고, 앱 재시작 뒤에는 저장된 누적 구간과 해금 목록을 다시 보여준다. 첫 플레이 사람 관찰은 [초안](W6_Desktop_First_Play_Observation_Draft_2026-09-23.md)만 준비했으며 아직 진행하지 않았다.
